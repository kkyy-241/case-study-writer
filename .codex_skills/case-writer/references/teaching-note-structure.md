# Teaching Note Structure

For this repository, use `supporting_documents/examples/安德科铭/安德科铭案例使用说明.pdf` as the default teaching-note format template. Match its document style and organization unless the user requests a different template.

## Required Sections

1. 案例摘要
2. 教学目标
3. 适用课程与对象
4. 讨论题及参考答案
5. 页脚尾注或尾注区，标注来自 `background` 文件夹的资料来源

Optional when useful:

- 课前准备建议
- 课堂板书/时间安排
- 附录：计算过程、估值表、股权稀释表、现金流测算

## Case Synopsis

Summarize the case in 1-3 paragraphs:

- Company, protagonist, industry, and development stage.
- Financing need and decision pressure.
- Alternatives and central conflict.
- The open decision point where the student case ends.

Do not write a marketing abstract. Make the teaching problem explicit.

## Teaching Objectives

Use 4-7 objectives. Good objectives start with verbs:

- 理解创业企业不同成长阶段的融资需求与风险特征。
- 分析信息不对称如何影响创业企业融资渠道、估值和契约条款。
- 比较债务融资、股权融资、风险投资、可转债、优先股等工具的适用条件。
- 评估估值、股权稀释、控制权和投资人增值服务之间的权衡。
- 设计兼顾融资效率、创始人控制和投资人保护的股权与治理安排。
- 运用案例事实形成融资决策建议并识别执行风险。

## Suitable Courses And Learners

Name the likely courses:

- 创业金融
- 公司金融/公司理财
- 风险投资与私募股权
- 企业估值
- 创业管理
- 并购融资, if relevant

Name the audience:

- 商学院本科高年级学生
- 金融、管理、会计、创新创业方向硕士研究生
- MBA/EMBA, if the case complexity supports it

## Reference Answer Pattern

For each of the five questions, answer in this structure:

1. 涉及理论: Introduce the finance theory or framework in concise academic language.
2. 结合案例分析: Apply the theory to specific case facts, using numbers and terms when available.
3. 方案比较: Compare alternatives by benefits, costs, risks, incentives, and implementation conditions.
4. 课堂结论: Offer a defensible answer while acknowledging assumptions and tradeoffs.

## Required Theory Coverage

Across the five answers, cover the theories most relevant to the case:

- Entrepreneurial financing theory and startup growth stages.
- Capital structure theory and its limits in early-stage firms.
- Pecking order theory.
- Information asymmetry, adverse selection, and signaling.
- Agency theory and moral hazard.
- Venture capital screening, staged financing, monitoring, and value-added services.
- Contract design: preferred equity, convertible instruments, liquidation preference, redemption, anti-dilution, ratchets, board/veto rights.
- Valuation: pre-money/post-money, dilution, comparable valuation, DCF/scenarios, real options for high-growth ventures.
- Control rights and equity arrangements: founder control, voting rights, holding platforms, option pools, governance.
- Financing-stage matching: seed, startup, growth, expansion, pre-IPO or exit.

## Tone Difference From Student Case

The teaching note should be direct, analytical, and theory-grounded. It may reveal recommended answers and calculations. It should not continue the story style of the case narrative.

## Source Notes

Use Chinese for the teaching note unless the user explicitly requests another language. For facts drawn from `background`, preserve traceability with footer-style endnotes. If true page footers are not technically available during drafting, include a clearly labeled `资料来源尾注` section and keep each note concise.
